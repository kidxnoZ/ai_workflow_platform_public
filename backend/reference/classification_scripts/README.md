# 参考分类脚本

每个脚本对应一种常见数据集结构，供 LLM 在生成分类脚本时作为 few-shot 参考。

## 使用原则

- LLM 读取这些脚本作为直觉参考，**不直接复用**
- 每个数据集的 `is_plot()` 规则必须从该数据集的目录名语义重新推导
- 脚本入口统一：接受 `--output` 参数，`_special/` 已在 output_path 内

## 脚本列表

| 文件 | 适用场景 |
|------|---------|
| `01_one_actor_per_folder.py` | 每个 CV 目录直接是角色目录，无二级结构 |
| `02_cv_hierarchy.py` | 一级 CV → 二级角色子目录（H42 型） |
| `03_flat_filename_pattern.py` | 所有音频在根目录，角色名编码在文件名中（G126 型） |
